Los archivos SVG se distribuyen sin modificaciones. Solo se usan en el Markdown renderizado, desde recursos locales. El texto Unicode original y el editor de práctica no cambian. Si falta un gráfico, se conserva el emoji original como texto con fuente alternativa.
