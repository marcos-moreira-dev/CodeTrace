**No es aún el catálogo offline publicado.** Los fragmentos pueden ser programas completos, demostraciones de tipos, diagnósticos deliberados o partes que necesitan otros archivos, dependencias o una configuración particular. Antes de reemplazar los fundamentos actuales se deben clasificar, completar solamente el contexto imprescindible y verificar los resultados. No ejecutar indiscriminadamente los fragmentos. El informe de comprobación aislada es diagnóstico, no aprobación de todos los ejemplos.
