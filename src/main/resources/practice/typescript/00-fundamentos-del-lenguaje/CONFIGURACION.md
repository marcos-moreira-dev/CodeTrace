# Configuración de práctica

TypeScript 7.0.2, Node 24 LTS, ES2022 y strict como base. Cada ejemplo autónomo se compila desde su carpeta con el comando que figura en la cabecera; cada proyecto con `tsc -p .`. En los negativos, usar `--noEmit`, nunca ejecutar. Los módulos se resuelven con NodeNext en los proyectos. Los comandos son independientes, sin variables de shell ni rutas temporales.
