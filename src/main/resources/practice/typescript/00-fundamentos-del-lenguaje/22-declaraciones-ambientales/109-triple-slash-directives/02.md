# Directiva de triple barra

La notación genérica de opciones no es una directiva de TypeScript válida. Usa `/// <reference path="./declaration.d.ts" />` para una declaración local; para opciones del compilador, configura `tsconfig.json` (`module`, `strict`, `noImplicitAny`, etc.). `tsc -p .` aplica la configuración. No se ejecuta una directiva ficticia.
